# SMV Website – Gymnasium Bad Königshofen

## Dateien
- `index.html` – Hauptseite
- `styless2.css` – vollständiges Design
- `script.js` – Mobile Navigation, Projekt-Dialoge und EmailJS-Kontaktformular

## Vor dem Einsatz anpassen
1. In `index.html` die drei Namen der Schülersprecher*innen ergänzen.
2. In den AK-Karten jeweils `NAME EINFÜGEN` durch die echte Leitung ersetzen.
3. Telefonnummer und Sprechstunden ergänzen.
4. In `script.js` ersetzen:
   - `YOUR_PUBLIC_KEY`
   - `YOUR_SERVICE_ID`
   - `YOUR_TEMPLATE_ID`
5. `datenschutz.html` und `impressum.html` neben `index.html` ablegen.
6. Falls echte AK-Fotos vorhanden sind, können die CSS-Platzhalter in den `.ak-photo`-Elementen durch `<img>`-Elemente ersetzt werden.

Das Kontaktformular enthält exakt die drei vorgesehenen Felder Name, E-Mail und Nachricht. Die Validierungs-, Lade-, Erfolgs- und Fehlerlogik aus der bereitgestellten Vorlage wurde beibehalten.
